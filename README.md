# Nightshade Station is now Mandrake

**Nightshade Station is now [Mandrake](https://github.com/Oliv3rmoon/Mandrake)**: same app, same title ID (PPSA98510), and your settings stay.

This repository only exists so that Nightshade Station 1.6.0 can update itself one last time. Its only release is Mandrake 1.6.1, with the same files as [Mandrake's own](https://github.com/Oliv3rmoon/Mandrake/releases/tag/1.6.1). Once it's installed, updates come from Mandrake.

- New releases, issues and source: https://github.com/Oliv3rmoon/Mandrake
- Mandrake is a Nightshade app, based on SwanStationPS5 by BlackBearReloaded. See Mandrake's README for credits and license.
